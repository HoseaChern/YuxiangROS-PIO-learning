# 两轮自平衡车笔记

> 对应固件：`src/tests/test10_balance`（阶段一：直立环 PD）
> 本文档随平衡车项目推进持续更新，记录设计决策、调试记录与调参数据。

## 1. 项目背景

在鱼香 ROS 差速底盘（`fishbot_motion_control`）基础上加装 MPU6050，拆下从动轮，
整车退化为一级倒立摆，通过电机闭环控制实现两轮自平衡。控制目标按三阶段递进：

| 阶段   | 内容                  | 状态               |
| ------ | --------------------- | ------------------ |
| 阶段一 | 直立环 PD（本固件）   | 已完成，待实测整定 |
| 阶段二 | 速度环 PI（自动寻中） | 规划中             |
| 阶段三 | 转向环 P（转向/航向） | 规划中             |

## 2. 控制理论

### 2.1 物理模型

双驱小车立起来后是一个一级倒立摆，动力学决定其天然不稳定：

- 不施加控制时，偏离竖直的角度会指数发散（重力矩加速倾倒）；
- 控制量（轮子转矩）通过"轮子往倒的方向跑"把支撑点接到重心下方；
- 两个硬约束：控制节拍必须快且稳（业界标准 5ms / 200Hz），极性必须是负反馈。

### 2.2 三环串级架构（业界主流方案）

```text
                 ┌─────────┐ 目标角偏移 ┌─────────┐        ┌────────┐
 target_v ──────►│ 速度环 PI │─────────►│ 直立环 PD │──────► │ 电机混合 │──► PWM_L/R
 (期望车速)       └─────────┘            └─────────┘        └────────┘
                  输入: 编码器车速(低通)    输入: pitch + gyro_y       ▲
                  输出: 目标角偏移 ±几度    输出: 主导 PWM             │
                                                                      │
 target_yaw ────► 转向环 P/PD ─── 差速量 ±pwm_turn ───────────────────┘
```

最终输出混合：`pwm_left = pwm_balance + pwm_turn`，`pwm_right = pwm_balance - pwm_turn`。

| 环     | 类型         | 输入                       | 输出       | 要点                                           |
| ------ | ------------ | -------------------------- | ---------- | ---------------------------------------------- |
| 直立环 | PD（不用 I） | pitch 误差 + gyro_y 角速度 | 主导 PWM   | D 项用陀螺仪而非误差微分，避免放大噪声         |
| 速度环 | PI           | 编码器车速（低通）         | 目标角偏移 | 不能直接调 PWM，只能改平衡点；积分消除稳态误差 |
| 转向环 | P/PD         | gyro_z 或 yaw 误差         | 差速量     | 起步用角速度方案，绕开 yaw 积分漂移            |

### 2.3 速度环自动寻中（阶段二关键）

速度环 PI 的积分项会自动收敛：车往 A 向漂 → 速度误差累积 → 目标角朝反方向偏 →
车回到平衡点。因此**加上速度环后，ZERO_PITCH 设为 0 也能自己站稳**。
当前 `'c'` 手动标定只是直立环阶段的临时手段，为速度环提供合理初值。

## 3. test10 固件设计

### 3.1 轴向约定与符号链

- 小车前进方向为 X 负方向（按 6050 丝印方向）；
- 前倾时 `gyro_y < 0`（由 v=ω×r 推得）；
- 固件内统一为"前倾为正"：`pitch = -getAngleY()`，`pitch_rate = -getGyroY()`；
- 输出再取负一次，最终 `pwm = KP·(pitch−中值) + KD·pitch_rate`：
  前倾出正 PWM，轮向车头方向转动接住重心。

**极性检验先于调参**：手扶车体前倾，轮子应向车头方向追；若反向，对调 config.h
中该电机 `PIN_A/PIN_B` 定义（或利用 `'d'` 自检命令验证）。

### 3.2 引脚与节拍

| 项目     | 值          | 说明                                                  |
| -------- | ----------- | ----------------------------------------------------- |
| I2C SDA  | GPIO10      | 从空闲集合 {3,46,9,10,11,12} 避开 strapping 3/46 选取 |
| I2C SCL  | GPIO9       | 同上                                                  |
| 控制节拍 | 5ms (200Hz) | FreeRTOS 任务 `vTaskDelayUntil` 固定周期，钉 core1    |
| 串口     | 115200      | 命令输入 + 状态文本输出（纯英文）                     |

### 3.3 串口命令

| 命令 | 功能             | 说明                                                  |
| ---- | ---------------- | ----------------------------------------------------- |
| `s`  | 启停武装切换     | 武装后姿态进入中值窗口才真正起控                      |
| `c`  | 机械中值在线标定 | 扶直静止后发送，取 0.2s 平均 pitch 生效               |
| `d`  | 极性自检         | 两轮 +PWM 输出 1s，轮子应朝车头转；反向则对调 PIN_A/B |

### 3.4 状态机与安全

- 上电默认 `kIdle` 停止，消除"平放上电误起控"问题（见 4.1）；
- 起控条件：已武装 且 `|pitch − 中值| < 8°`；
- 倒地保护：`|pitch − 中值| > 45°` 自动解除武装并停机，扶正后可重新起控。

## 4. 调试记录

### 4.1 "平放一直前进"根因与修复

**根因**：MPU6050_light 的角度基准是**上电校准时刻的姿态**——平放上电，平放即恒
读 0°，旧版 `|pitch|<8°` 起控条件被永久满足 → 一上电就闭环；而 `ZERO_PITCH=0`
未标定真实直立中值，P 项恒有偏差输出 → 单向漂移狂奔；前进加速度的反作用力矩使
车身后仰，松手即倒。

**修复**：上电默认停止，串口命令显式控制启停（`'s'`），并在起控前复位 PID 内部
状态（`reset()`）。

### 4.2 终端乱码问题

根因是 `pio run -t upload` 成功后会自动打开串口监视器，显示 ESP32 ROM boot 的
74880 波特率乱码。固件无问题，烧录命令加 `--no-monitor`：

```bash
pio run -e test10_balance -t upload --no-monitor
```

### 4.3 调参顺序（业界共识）

1. 直立环 Kp：从 25 起调至出现低频振荡；
2. 直立环 Kd：从 0.5 加至振荡消失、手感变"硬"；
3. 速度环 Ki（主）→ 小 Kp（阶段二）；
4. 转向环（阶段三）；
5. 每次只动一个参数。

实测静止站立的平均 pitch 填入 `BALANCE_ZERO_PITCH_DEG`（或用 `'c'` 在线标定）。

## 5. 推荐调试流程

1. 平放静置上电 → 等校准完成提示；
2. 发 `d` 确认轮子转向朝车头（极性物理验证）；
3. 手扶车体大致直立 → 发 `c` → 看 `[CALIB] zero_pitch=xx.xx`；
4. 发 `s` 武装 → 松手观察；串口每 100ms 输出一行状态文本：
   `state=RUN pitch=1.23 rate=-0.45 pwm=12`。

## 6. 环境与工具注意事项

- pio 不在 PATH，用 `~/.platformio/penv/bin/pio`；
- `~/.gitconfig` 为 github.com 配置了 Clash 代理（127.0.0.1:7897），Clash 未运行时
  pio 拉取 VCS 库会失败，用 `GIT_CONFIG_GLOBAL=/dev/null` 绕过直连。
