# PIDController 库

位置式 PID 控制器库，为电机速度环/直立环提供闭环控制。纯算法层，仅依赖 `<cstdint>` 与 `<cmath>`，不触碰 Arduino 头文件与硬件外设，便于单元测试与跨平台移植。历次优化记录已并入仓库根目录 README.md。

> 数学公式使用 LaTeX 渲染（支持 KaTeX/MathJax 的预览器可正确显示）。

## 1. 数学原理

本节忠实于标准 PID 控制理论。当前实现即按此理论构造，实现细节见「2. 库介绍」。

### 1.1 连续时间标准 PID

$$
u(t) = K_p e(t) + K_i \int e(\tau)\,d\tau + K_d \frac{de(t)}{dt}
$$

$$
e(t) = r(t) - y(t) \qquad (r:\text{目标},\ y:\text{测量})
$$

式中比例（$P$）、积分（$I$）、微分（$D$）三项的物理含义见 1.5。

### 1.2 离散化与采样周期 $T$

固定采样周期 $T$ 下，对连续项做离散近似：

$$
\text{积分项}:\ \int e\,d\tau \approx \sum_{j=1}^{k} e_j \cdot T \qquad (\text{矩形法})
$$

$$
\text{微分项}:\ \frac{de}{dt} \approx \frac{e_k - e_{k-1}}{T} \qquad (\text{一阶后向差分})
$$

代入连续式，得离散位置式：

$$
u_k = K_p e_k + K_i T \sum_{j=1}^{k} e_j + \frac{K_d}{T} (e_k - e_{k-1})
$$

### 1.3 系数吸收法

将采样周期吸收进增益，令 $K_i' = K_i T$、$K_d' = K_d / T$，得到离散位置式的等价形式：

$$
u_k = K_p e_k + K_i' \sum_{j=1}^{k} e_j + K_d' (e_k - e_{k-1})
$$

此为标准离散化的一种合法化简，$T$ 从公式中消去，三个增益同量纲（见 1.6）。代价是增益与采样周期 $T$ 强耦合，改变 $T$ 后须重新整定。

### 1.4 位置式与增量式

**位置式**输出绝对控制量 $u_k$，由误差历史累积决定：

$$
u_k = K_p e_k + K_i' \sum_{j=1}^{k} e_j + K_d' (e_k - e_{k-1})
$$

**增量式**对位置式相邻两拍输出做差（增量化），输出控制量增量 $\Delta u_k = u_k - u_{k-1}$：

$$
\Delta u_k = K_p (e_k - e_{k-1}) + K_i' e_k + K_d' (e_k - 2 e_{k-1} + e_{k-2})
$$

控制原理上，增量式等价于对位置式施加一阶差分算子 $\Delta u_k = (1 - z^{-1}) u_k$。其特点如下：

| 类型   | 输出              | 特点                                               |
| ------ | ----------------- | -------------------------------------------------- |
| 位置式 | 绝对控制量 $u_k$  | 累积全部历史误差，需积分限幅防饱和                 |
| 增量式 | 增量 $\Delta u_k$ | 仅依赖最近几拍，无累积饱和，需外部累加执行机构位置 |

### 1.5 各环节的作用与整定

三张原理图均以水池注水、日常倒水等物理类比说明各环节。PID 三项不一定全部参与，需按被控对象取舍（见「总结」）。

#### 比例环节 $K_p e_k$

- 即时响应当前误差，误差越大，输出越强。
- $K_p$ 越大，系统响应越快、越接近目标值；
- $K_p$ 过大，超调与振荡加剧，稳定性变差；
- 仅比例环节无法消除稳态误差。

#### 积分环节 $K_i \sum_{j=1}^{k} e_j$

- 累积历史误差，用于消除稳态误差。
- $K_i$ 越大，越早消除静差、越快达到目标；
- $K_i$ 过大，超调与振荡加剧，稳定性变差；
- 随时间推移积分项不断累加，过大累积反而使响应变慢（积分饱和）。

  **积分限幅**：为防止积分值过大导致响应滞后，对积分累积幅度加以限制。

  **积分分离**：稳态误差只在接近目标值时出现。为防饱和，误差大时仅用比例，误差小于设定阈值后才引入积分。

#### 微分环节 $K_d (e_k - e_{k-1})$

- 响应误差变化趋势，提前抑制超调与振荡（阻尼）。
- $K_d$ 或误差变化趋势越大，对超调、振荡的抑制越强；
- $K_d$ 过大易诱发振荡并引入高频噪声。

#### 总结

PID 三项不必然全部使用。例如小车直立平衡为追求快速响应用 **PD** 控制；轮子速度控制为避免振荡、保证平滑用 **PI** 控制。

### 1.6 各系数物理含义与量纲

以速度环为例（误差单位 mm/s，输出单位 PWM，$T$ 单位 s）：

| 系数               | 单位       | 物理作用                                 |
| ------------------ | ---------- | ---------------------------------------- |
| $K_p$              | PWM/(mm/s) | 响应即时误差，过小迟滞、过大超调         |
| $K_i'$（$=K_i T$） | PWM/(mm/s) | 消除稳态误差，但引入相位滞后，过大致振荡 |
| $K_d'$（$=K_d/T$） | PWM/(mm/s) | 提供阻尼、抑制超调，对噪声敏感           |

吸收 $T$ 后三个增益量纲一致，便于统一整定。

## 2. 库介绍

### 2.1 作用

- 控制计算：由目标值与当前值误差，按 $P/I/D$ 求和得到 PWM 占空比。
- 限幅保护：积分限幅防饱和，输出限幅保护执行机构。
- 状态管理：支持运行时更新目标、增益、限幅；`reset()` 复位内部状态。

### 2.2 文件说明

| 文件                | 说明               |
| ------------------- | ------------------ |
| `PIDController.h`   | 类声明与接口       |
| `PIDController.cpp` | 核心算法与状态实现 |
| `docs/README.md`    | 本文档             |

### 2.3 公共接口

| 方法                           | 说明                                                                   |
| ------------------------------ | ---------------------------------------------------------------------- |
| `update_pid(kp, ki, kd)`       | 设定 $P/I/D$ 增益，不重置内部状态                                      |
| `output_limit(limit)`          | 设定对称输出限幅 ±limit                                                |
| `update_target(target)`        | 设定目标值                                                             |
| `update_pwm(current)`          | 数值微分变体：$D$ 项 $\Delta e$ 取误差差分 $e_k - e_{k-1}$             |
| `update_pwm_with_rate(inputs)` | 外部微分变体：形式同左，$\Delta e$ 取测量( $y$ )变化率的相反数 $-rate$ |
| `reset()`                      | 清零内部状态，重新起控前调用                                           |

### 2.4 使用示例

```cpp
PIDController pid;
pid.update_pid(1.0f, 0.1f, 0.05f);  // P/I/D 增益
pid.output_limit(100.0f);            // 输出限幅 ±100
pid.update_target(200.0f);           // 目标速度 200 mm/s

// 控制周期内调用：传当前速度，得 PWM
int16_t pwm = pid.update_pwm(current_speed);
```

### 2.5 设计特性

- 单精度优先：全程 `float` 与 `f` 后缀，适配 ESP32-S3 单精度运算。
- C++11 兼容：`INTEGRAL_SUP_LIMIT` 用 `static constexpr` 并在 `.cpp` 提供类外定义，避免 ODR-use 链接错误。
- 成员默认初始化 `= 0.0f`，默认构造后即可调用，无未定义行为。
- 限幅收敛用 `std::fmax`/`std::fmin` 单行实现。
- 输出四舍五入而非向零截断，避免低速时占空比系统性偏小。

### 2.6 注意事项

- `update_pid()` 不重置内部状态，历史保留。
- 构造后须先 `output_limit()` 设定限幅，否则输出恒为 0（默认 `output_limit_ = 0.0f`）。
- 同一实例勿混用 `update_pwm` 与 `update_pwm_with_rate`（共享积分状态；两者 $D$ 项数学量同为 $\Delta e$，仅计算来源不同）。
